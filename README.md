# Ranges Expresso 3-max

Application web statique pour consulter et travailler des ranges préflop d'Expresso 3-max.

## Fichiers

- `index.html` : structure de la page
- `styles.css` : design de l'interface
- `ranges.js` : données de ranges
- `app.js` : grille 13×13 et interactions
- `.nojekyll` : compatibilité GitHub Pages

## Mise en ligne avec GitHub Pages

Dépose tous les fichiers à la racine du dépôt GitHub, puis active GitHub Pages sur la branche principale.

## État actuel

Les ranges présentes sont des données de démonstration destinées à valider l'interface. Elles seront remplacées par les ranges théoriques choisies pour chaque profondeur et chaque spot.
